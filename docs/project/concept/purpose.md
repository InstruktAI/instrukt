# Purpose — Concept

## What

## Why

A frontier model already knows how to write code. What it cannot know is what
is true on a machine, in a codebase and in a business. Instrukt keeps that
knowledge in git, as documentation reviewed like code, and gives agents the
exact piece a task needs at the moment they need it.
