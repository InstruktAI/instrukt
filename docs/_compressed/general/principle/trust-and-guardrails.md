- agents are trusted by default; a guardrail only where restoring state cannot repair harm: interference (two agents on one object) | contract changed under its executor; all else = direction in the brief.
- reversibility is engineered in the state layer (versioned records, soft removal); an irreversible mutation = state-layer defect to repair, NEVER a permission rule.
- a gate MUST read the object (holder, phase), NEVER caller rank, and MUST name its door: the sanctioned path keeping the invariant -- a door is a path, not a decision.
- a refusal = moment judgment is required: stop and tell someone.
- integrity gates have no human bypass; involvement records are audit only; live human direction through an eligible authoring session is not blocked by autonomous-agent conflict rules.
- a needed new gate -> widen the object model, NEVER add a call site.
